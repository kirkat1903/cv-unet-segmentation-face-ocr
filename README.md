# CV/ML Pet-проекты

Три самостоятельных мини-проекта по компьютерному зрению для портфолио.
Каждый файл — отдельный проект, их можно разложить по разным репозиториям
или оставить вместе.

## Установка

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Для `face_verification.py` и `ocr_extraction.py` желательна GPU (CUDA) —
но оба работают и на CPU, просто медленнее (в коде есть флаг `gpu=False`).

---

## 1. `segmentation_unet.py` — Сегментация изображений (U-Net)

Полная реализация U-Net на PyTorch «с нуля»: энкодер-декодер со skip-connections,
Dataset для пар (изображение, маска), обучение с метрикой Dice.

**Что нужно подготовить:**
```
data/
  train/
    images/  *.jpg
    masks/   *.png   (0 = фон, 255 = объект)
  val/
    images/
    masks/
```

**Запуск:**
```bash
python segmentation_unet.py
```
Лучшая модель по Dice сохраняется в `unet_best.pth`.

**Куда применить:** дефекты на деталях, дороги на аэрофото, медицинские снимки —
любая задача «выделить объект по пикселям».

---

## 2. `face_verification.py` — Верификация и идентификация лиц

Пайплайн MTCNN (детекция + выравнивание лица) → InceptionResnetV1
(предобучен на VGGFace2, эмбеддинг 512-d) → сравнение по косинусному расстоянию.

**Возможности:**
- регистрация лица в локальную базу (`face_db.pkl`)
- верификация 1:1 (`verify`) — «это точно тот же человек?»
- идентификация 1:N (`identify`) — «кто это из базы?»
- демо с веб-камеры в реальном времени

**Запуск:**
```bash
python face_verification.py
```
В окне: `r` — зарегистрировать текущее лицо, `q` — выход.

**Куда применить:** система контроля доступа, автоматическая отметка
посещаемости, поиск дубликатов лиц в фотоархиве.

---

## 3. `ocr_extraction.py` — OCR (извлечение текста из изображений)

EasyOCR с поддержкой русского и английского из коробки + предобработка
на OpenCV (шумоподавление, адаптивная бинаризация, выравнивание наклона).

**Запуск:**
```bash
python ocr_extraction.py
```
Положите изображение в `data/sample_document.jpg` (или поменяйте путь в `main()`).
Результат сохраняется в `output.txt` (чистый текст) и `output.json`
(текст + координаты боксов + уверенность распознавания).

**Куда применить:** распознавание сканов документов, чеков, форм,
извлечение текста с фото для последующей обработки.
